AC/DC (Bon Scott Era) — LoKR Dataset Caption Cheat Sheet (Corrected)

    Scope: ACE-Step 1.5 XL, SFT variant, LoKR training. Bon Scott years only (1974–1980).

    This cheat sheet replaces all previous caption advice for this project. The previous version was written for generation prompting, not training annotation.

1. The Core Principle Applied to Your Dataset

Your dataset has two layers:
Layer	Contents	Where it goes
Common variables	Everything that makes the sound "AC/DC Bon Scott era" and appears in every song	Omitted from captions — absorbed by your trigger tag
Variable elements	What differs between songs in your dataset	Written in captions — described per song

Your trigger tag (e.g., acdc_bs or bon_scott_style or whatever you choose) becomes the on/off switch. Trigger on → AC/DC Bon Scott sound. Trigger off → base model default.

If you leave common variables in the captions, three failures occur:

    The trigger becomes a weighted blend rather than a clean switch.

    Writing the common tags without the trigger still leaks the trained style.

    The adapter may degrade when the common tags are absent from a prompt.

3. INCLUDE in Captions (Variable Elements)

These are what differs between songs in your Bon Scott dataset. Describe these per song.
Song-Specific Tempo & Feel

Not the BPM number (that goes in JSON), but the character: slow bluesy burn, mid-tempo swagger, fast driving rocker, half-time stomp, shuffle feel, straight eighth-note drive.
Song-Specific Structural Arrangement

What actually happens in this track: opens with solo guitar riff before drums enter, starts with acapella vocal line, chorus arrives after only one verse, extended outro jam, false ending before final chorus.
Song-Specific Solo Character (See §4)

The specific techniques and tone used in this song's solo, not the generic AC/DC solo vocabulary.
Song-Specific Lyrical Themes

What the song is about, if relevant: party anthem about a woman, tribute to a rock venue, song about touring, dark narrative about a killer, blues lament.
Song-Specific Instrumental Variations

Any instrument that appears in this track but not others: harmonica intro, piano accompaniment, slide guitar, acoustic guitar section, bagpipes (if applicable — check your actual tracks).
Song-Specific Dynamic Contrast

If the track has unusual dynamics: quiet verse to explosive chorus, builds from sparse to full band, breakdown to just bass and drums, sudden stop.
Song-Specific Backing Vocal Patterns

If call-and-response happens in a specific way in this track: gang vocals on chorus, Malcolm and Cliff answer Bon's lines, shouted backing on the title phrase, no backing vocals in this section.

6. Model Variant Note (SFT)
Aspect	SFT (your variant)	Turbo	Base
CFG support	✅ Yes — metadata conditions output	❌ No	✅ Yes
Alignment logic	Preserved	Cut (distillation)	Preserved
Metadata in JSON	Critical — accurate bpm/keyscale/timesignature	Less impactful	Critical
Caption detail	Can handle detailed variable descriptions	Needs simplification	Can handle detail
Trigger omission principle	Applies fully	Applies fully	Applies fully

The omission principle is variant-independent. It is a property of how LoKR adapters learn, not of the base model. SFT is the correct variant because it preserves the alignment logic that makes the trigger→sound binding precise.
7. Quick Reference
Action	Detail
Trigger tag	Choose one. Use it in every generation prompt. It absorbs all omitted common variables.
Captions	Describe only what differs between songs.
Guitar solos	Describe the specific solo character per track, not the generic AC/DC solo style.
Metadata	BPM, key, time signature go in JSON. Never in captions.
Model variant	SFT. Preprocess with --model-variant sft.
Max caption length	512 tokens; 5–12 front-loaded keywords (if any) + 2–3 variable sentences.
Default caption	Never use one. It teaches a vague average.
The One-Sentence Rule

    If a feature appears in every song in your dataset, it does not appear in any caption. The trigger tag is the only name for that feature.
